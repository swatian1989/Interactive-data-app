# Interactive Data Analysis Platform

A comprehensive Streamlit-based data analysis platform featuring advanced statistical testing, machine learning, and exploratory data analysis capabilities.

## 🚀 Features

### Core Data Management
- **Multi-format Data Upload**: Support for CSV, Excel (.xlsx, .xls), and JSON files
- **Automatic Encoding Detection**: Robust file parsing with encoding detection
- **Data Validation**: Built-in error handling and data type inference
- **Manual Data Entry**: Interactive forms for adding new data records

### Advanced Analytics & Statistical Testing
- **Comprehensive Statistical Tests**: t-tests, chi-square, ANOVA, normality tests
- **Machine Learning Models**: Regression, classification, clustering, PCA
- **Outlier Detection**: Multiple algorithms including IQR, Z-score, Isolation Forest
- **Correlation Analysis**: Pearson, Spearman, and Kendall correlations with significance testing

### Interactive Visualizations
- **Plotly Integration**: Interactive charts with customizable themes
- **Multiple Chart Types**: Scatter plots, histograms, box plots, heatmaps
- **Dashboard Builder**: Multi-component dashboard creation
- **Real-time Updates**: Dynamic visualizations that update with data changes

### Data Profiling & Quality Assessment
- **Automated EDA Reports**: Comprehensive data quality metrics and recommendations
- **Missing Data Analysis**: Detailed missing value patterns and suggestions
- **Distribution Analysis**: Statistical distribution assessment and testing
- **Data Quality Scoring**: Automated quality metrics for completeness, uniqueness, consistency

## 🛠️ Technology Stack

- **Framework**: Streamlit for web application interface
- **Data Processing**: Pandas, NumPy for data manipulation
- **Visualization**: Plotly Express, Matplotlib, Seaborn
- **Statistics**: SciPy, Statsmodels for statistical computing
- **Machine Learning**: Scikit-learn for ML algorithms
- **File Handling**: OpenPyXL for Excel file processing

## 📊 Application Structure

The platform features a modular 8-page architecture:

1. **📁 Data Upload** - File management and dataset loading
2. **🔍 Data Exploration** - Interactive filtering and basic analysis
3. **📈 Visualizations** - Chart creation and customization
4. **📊 Dashboard** - Multi-component dashboard builder
5. **✏️ Data Entry** - Manual data input capabilities
6. **🧪 Advanced Analytics** - Machine learning and predictive modeling
7. **📋 Statistical Tests** - Comprehensive hypothesis testing
8. **🔎 Data Profiling** - Automated data quality assessment

## 📈 Usage Examples

### Basic Workflow
1. **Upload Data**: Start by uploading your dataset using the Data Upload page
2. **Explore**: Use Data Exploration to understand your data structure and patterns
3. **Analyze**: Apply statistical tests or machine learning models as needed
4. **Visualize**: Create charts and build comprehensive dashboards
5. **Report**: Generate automated data profiling reports

### Advanced Features
- **Statistical Testing**: Perform normality tests, correlation analysis, and hypothesis testing
- **Machine Learning**: Build predictive models with cross-validation and performance metrics
- **Quality Assessment**: Get automated recommendations for data improvement
- **Outlier Detection**: Identify and analyze outliers using multiple detection methods
